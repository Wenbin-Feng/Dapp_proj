## 已覆盖的关键行为

- 制造商登记、大小写不敏感的序列号唯一性、UUID、保修参数边界。
- 管理员角色授权、禁止自行提升权限、禁止旧 API 绕过合约修改业务记录。
- 制造商 → 零售商 → 消费者 → 消费者的转移方向、发送/接收方权限、接受/拒绝/撤销。
- 首次零售接受启动保修；转售保留起止日期、已用额度和维修历史。
- 指定服务中心审批、拒绝和维修完成；完成才扣额度、不能重复完成、额度耗尽拒绝新申请。
- 到期前一秒与准确到期时的差异；到期前已提交的维修可在到期后完成。
- 待处理转移和未结束保修互斥；其他钱包不能审批或冒领操作。
- 私密正文不上链、公共查询不含维修正文、正文通过加盐承诺校验。
- 交易已广播但确认请求丢失时恢复；重复同步不会多扣额度或重复创建历史。
- 伪造回执、他人操作 ID、部署身份变化、已索引区块重组均被拒绝。
- 直接调用合约后的事件索引；从零重建 SQLite 业务状态，缺失私密文本时明确标注不可用。
- 拒绝无法解码的 UTF-8、空型号和超长元数据，避免合法上链事件阻塞数据库同步。
- 浏览器钱包拒绝交易、自动添加/切换本地网络、账户切换撤销会话、手机宽度无横向溢出。
